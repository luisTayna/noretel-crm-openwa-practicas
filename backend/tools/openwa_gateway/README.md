# OCR para Yape

El puente `yape_ocr_server.py` es opcional. Configure `YAPE_OCR_REMOTE_SECRET`, `YAPE_OCR_PARSER_PATH` y el endpoint de prueba mediante variables de entorno; no utilice credenciales, servicios ni capturas de clientes reales. El parser se encuentra en `tools/yape_monitor/parse_image.py`.
